Two harnesses. You already have both. You own neither.

The small one is the agent harness: instruction files, hooks, sandbox, evals, around one coding agent doing one job. It got a name this year. It's real and worth having.

The big one is the Enterprise AI Harness: context, orchestration, governance and execution, around a rented model. Every enterprise running a model in production has one. Most built it by accident, one copilot at a time.

Thursday's essay defines both, makes the ownership claim (the enterprise in the driver's seat, partners helping), and opens the repo: a reference architecture and a reference implementation, built in public, spec first. No runtime yet, on purpose.
