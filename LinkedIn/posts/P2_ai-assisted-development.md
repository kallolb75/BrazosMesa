# P2: AI-assisted development

LinkedIn, Thu Oct 8, 2026. Image: [P2_ai-assisted-development.png](../infographics/P2_ai-assisted-development.png)

AI-assisted development changes who can drive the build.

You can write code in any AI assistant today. Describe what you want, accept what comes back, paste in the error when it breaks. Andrej Karpathy called this "vibe coding" in February 2025.

It's useful. For a prototype, it's often the fastest way to learn what you need.

Production asks for more than code that runs: a spec written before the code, tests that encode the requirement, limits on what the agent can touch, and someone who can explain every line.

Generation got cheap. The hard part moved to understanding, checking and owning what was generated.
