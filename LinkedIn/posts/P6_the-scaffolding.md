# P6: Start with four pieces. Grow in rings.

LinkedIn, Sat Oct 17, 2026. Image: [P6_the-scaffolding.png](../infographics/P6_the-scaffolding.png)

That's the series. Here's where it goes.

Start with four pieces, in this order. Each one answers an ownership question.

1. Model gateway. Configuration, so the model is swappable on day one.
2. One MCP server. In front of one real system, with its own auth and schema.
3. Trace log. An event schema you wrote. Every retrieval, call and decision can be replayed.
4. Eval suite. The definition of done. Runs before anything ships.

Then grow in rings, as the workflow demands: retrieval, memory, policy gates, a second system.

The architecture unwrapped, the layers designed, the scaffolding built. I'll write it up as it happens, on Substack. Free to read.
